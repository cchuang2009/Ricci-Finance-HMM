# Ricci-Finance V16 — Multi-Modal Financial Network Intelligence

## V16 Development Philosophy

V16 is designed as a **step-by-step processing pipeline**.

The goal is not simply to add more visualization or machine-learning models. Each new module should use information generated by the previous stage and add a new interpretation of the same financial market.

The overall idea is:

```text
Yahoo Finance Data
       ↓
Data Preparation
       ↓
Multi-Sector Information
       ↓
Rolling Financial Network
       ↓
Financial Distance
       ↓
Ollivier–Ricci Curvature
       ↓
Dynamic Communities
       ↓
Sector Momentum
       ↓
Capital Flow
       ↓
HMM / Viterbi
       ↓
GNN / GAT
       ↓
Embedding / Clustering
       ↓
UMAP / t-SNE
       ↓
Temporal Network
       ↓
3-D Galaxy
```

The central design principle is:

> **One evolving financial network, multiple analytical views.**

# Step 3 — Calculate Returns

## What we add

Convert price data into returns.

For log returns:

$$
r_i(t)
=
\log
\left(
\frac{P_i(t)}
{P_i(t-1)}
\right)
$$

Typical implementation:

```python
returns = np.log(close / close.shift(1))
```

**Note**, $\{\log P_i(t)\}$ makes the data distributed more normally than  $\{ P_i(t)\}$.


## Why returns instead of prices?

Stocks with different absolute prices cannot be compared directly.

For example:

```text
NVDA = $180
AMD  = $160
```

does not tell us how similarly they behave.

Returns describe **relative movement**.

The financial network should therefore be constructed from:

```text
Price
 ↓
Return
 ↓
Relationship
```

rather than:

```text
Price
 ↓
Relationship
```

## Output

A return matrix:

```text
             NVDA   AMD   AVGO   ...
Date 1
Date 2
Date 3
...
```

becomes the main input for Step 4.


## Why rolling windows?

A single correlation matrix assumes that the relationships between stocks are stable.

That is usually unrealistic.

For example:

```text

Crisis:
Everything becomes highly correlated

Recovery:
Different sectors separate again
```

The financial network therefore needs to be treated as:

$$

$$

rather than one fixed graph:

$$

$$

## Output

A sequence:

```python

    G_t1,
    G_t2,
    G_t3,
    ...
]
```

This becomes the fundamental temporal structure of V16.

# Step 5 — Correlation and Financial Distance

## What we add

Calculate rolling correlations first:

$$\rho_{ij}=\text{corr}(r_i,r_j)$$

Then transform correlation into financial distance:

$$d_{ij}=\sqrt{2(1-\rho_{ij})}$$

**Note**, $-1\le\rho_{ij}\le1,$ but $ 0\le d_{ij}\le2,$ always non-negative.

## Why not use correlation directly?

This is an important conceptual decision in Ricci-Finance.

Correlation tells us **how similarly two stocks move**.

But Ricci geometry requires a notion of **distance**.

Correlation has a useful geometric transformation:

$$
d_{ij}
=
\sqrt{2(1-\rho_{ij})}
$$

which has desirable properties for constructing a distance-based financial network.

Therefore:

```text
Correlation
     ↓
Financial Distance
     ↓
Metric-like Financial Geometry
     ↓
Ricci Curvature
```

rather than:

```text
Correlation
     ↓
Ricci Curvature
```

The distinction is fundamental.

## Code

Possible functions:

```python

correlation_to_distance(...)
build_distance_matrix(...)
```

in:

```text
ricci_finance/graph.py
```

## Output

A distance matrix:

```text
             NVDA   AMD   AVGO
NVDA          0    d12   d13
AMD         d21     0    d23
AVGO        d31    d32    0
```

# Step 7 — Calculate Ollivier–Ricci Curvature

## What we add

Calculate Ollivier–Ricci curvature on the financial graph.

Possible implementation module:

```text
ricci_finance/ricci.py
```

using:

```text
GraphRicciCurvature
```

or the project's existing Ricci-curvature implementation.

## Concept

For an edge $(x,y)$, Ollivier–Ricci curvature compares probability distributions around the two nodes.

Conceptually:

```text
Neighborhood of x
        ↓
    Distribution
        ↘
         Compare
        ↗
    Distribution
        ↓
Neighborhood of y
```

The curvature is related to the Wasserstein distance between the two neighborhood distributions.

A simplified relationship is:

$$\kappa(x,y)=1-\frac{W(m_x,m_y)}{d(x,y)}$$

where:

- $d(x,y)$ is the edge distance
- $m_x,m_y$ are neighborhood probability distributions
- $W$ is Wasserstein distance

## Why Ricci curvature instead of correlation?

Correlation answers:

> **How similarly do two stocks move?**

Ricci curvature asks a deeper structural question:

> **How does the local neighborhood around one stock compare with the neighborhood around another stock?**

This distinction is critical.

Consider:

```text
A ─── B
│     │
C ─── D
```

and:

```text
A ─── B       X ─── Y
```

An individual edge correlation may look similar, but the surrounding topology is completely different.

Ricci curvature incorporates **local network geometry**, not merely pairwise correlation.

Therefore:

```text
Correlation
    = pairwise similarity

Ricci curvature
    = local geometric structure
```

## Output

Each edge receives:

```python
G[u][v]["ricciCurvature"]
```

This becomes the basis for:

- curvature visualization
- community analysis
- Ricci surgery
- graph features
- temporal analysis

# Step 16 — GAT Attention

## What we add

Use Graph Attention Networks to learn different importance weights for neighboring stocks.

Possible implementation:

```python
GAT(...)
```

## Concept

Instead of:

```text
All neighbors = equal importance
```

GAT learns:

```text
Neighbor A → high attention
Neighbor B → low attention
Neighbor C → medium attention
```

## Why?

A financial network may contain many edges, but not all relationships are equally informative.

GAT therefore provides:

```text
Graph structure
      ↓
Learned relationship importance
```

This can complement Ricci curvature.

Ricci asks:

> What is the geometric structure of the neighborhood?

GAT asks:

> Which neighbors are most useful for the learned representation?

# V16 — Why These Methods Are Combined

V16 deliberately combines methods that answer different questions.

| Method | Main Question |
|---|---|
| **Correlation** | Do two stocks move similarly? |
| **Financial Distance** | How far apart are two stocks in market geometry? |
| **Ricci Curvature** | What is the local geometry of their network relationship? |
| **Community Detection** | Which stocks form structural groups? |
| **Sector Mapping** | What economic themes do the stocks belong to? |
| **Sector Momentum** | Which economic themes are strengthening? |
| **Capital Flow** | Where is market participation moving? |
| **HMM** | What hidden market regime may explain the observations? |
| **GNN** | Can useful graph representations be learned automatically? |
| **GAT** | Which relationships are important to the learned representation? |
| **UMAP / t-SNE** | What does the learned latent structure look like visually? |
| **Galaxy** | Can the entire market structure be represented spatially? |

The methods are therefore not redundant.

They form complementary layers:

```text
                    Financial Market
                          │
        ┌─────────────────┼──────────────────┐
        ↓                 ↓                  ↓
     Geometry          Economics           ML
        │                 │                  │
   Ricci curvature   Sector momentum    GNN / GAT
   Distance          Capital flow       Embedding
        │                 │                  │
        └─────────────────┼──────────────────┘
                          ↓
                  Market Structure
                          ↓
                  Temporal Evolution
                          ↓
                       Galaxy
```

# V16 Core Research Idea

The fundamental V16 hypothesis is:

> **A financial market cannot be fully described by correlation alone.**

Correlation captures pairwise co-movement.

Ricci curvature adds local geometry.

Communities add topology.

Sectors add economic semantics.

Capital flow adds market-participation information.

HMM adds hidden temporal states.

GNN adds learned representations.

Temporal analysis connects all of these dimensions.

Therefore the V16 architecture attempts to construct:

$$\text{Market Intelligence}=f(
\text{Geometry,Topology,Economics,Flow,Temporal Stat,Learned Representation})$$

The final objective is not to replace one representation with another, but to determine whether these different representations **agree, disagree, or reveal different aspects of evolving market structure**.
